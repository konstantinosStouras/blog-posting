# Blog Posting

A lightweight student blog canvas. Open `index.html` in a browser; no build or dependencies required.

Features: responsive cards, topic filters, search, full story reader, and a post form. Posts use localStorage in the current browser. Fictional sample stories are included. This prototype has no accounts, shared database, moderation, or multi-user publishing.

## GitHub Pages
In repository Settings → Pages, deploy from the `main` branch, `/ (root)` folder.
